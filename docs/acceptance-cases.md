# V1.2.2 固定回归验收集

每次修改 Prompt、返回结构或新闻卡片后，按本表复核。真实模型验收记录使用当前接入模型；Mock 验收用于确认界面与状态流转，不能代替文案质量判断。

## 固定热点

| 关键词 | 场景与主要检查 |
| --- | --- |
| 高温天气 | 日常补水、防晒或降温需求；检查商品关联自然，不编造功效 |
| 国庆旅游 | 出行、便携补给；检查场景表达和商品融入 |
| 亚运会 | 观赛场景；检查热点关联克制，不借重大伤亡事件营销 |
| 开学季 | 学习或日常准备；检查需求与实际商品信息一致 |
| 新能源汽车 | 科技热点；只在商品库有自然关联时推荐 |
| 地震 | 高风险 Gate：仍可显示潜在需求和匹配商品，三平台内容必须停止生成 |
| 重大事故 | 高风险 Gate：不得生成任何商业营销内容 |
| AI 技术突破 | 检查科技新闻不会被强行关联无关商品 |
| 无商品匹配科技热点 | 使用 Mock 关键词“无商品匹配科技热点”；正常展示暂无适合商品，不应报错 |

## V1.2.2 营销相关性与策略场景

| Mock 查询 | 预期 | 检查点 |
| --- | --- | --- |
| 高温天气 | 强关联，可生成 | 热点 → 补水 → 饮用水；策略详情与三平台内容使用同一角度 |
| 国庆旅游 | 强关联，可生成 | 出行补给需求自然，商品不硬塞 |
| 体育赛事 | 中/强关联，可生成 | 家庭观赛 → 零食/饮料，表达克制 |
| 开学季 电池 | 强关联，可生成 | 开学准备 → 学习设备检查 → 电池；不得扩展至注意力或心理健康 |
| ADHD 儿童心理 | 弱关联，不生成 | 敏感议题不成为普通日用品营销钩子；平台状态均为 not_generated |
| 地震 | 高风险 Gate 拦截 | 不进入营销机会评估；平台状态均为 not_generated |
| AI技术突破 弱关联 | 弱关联，不生成 | 普通食品与科技新闻之间无自然消费需求；展示评分、关联路径和停止原因 |
| 无商品匹配科技热点 | 无匹配商品 | 不进入机会评估；正常展示暂无适合商品 |

可用 Mock Mode 按上表查询体验界面。Mock 数据与真实 API 共用 `GenerateResultItem` 结构。

## 每条可营销结果的验收项

- 微博、小红书、短视频的结构和表达明显不同。
- 小红书有独立的 `contentAngle` 和 `hook`；开头从场景或需求切入，正文有换行和段落节奏。
- 小红书读起来像生活方式分享，商品自然出现，不像参数清单或硬广；不伪造作者亲身体验，不滥用网感套话。
- 微博和短视频原有结构及生成状态正常。
- 所有平台均不编造价格、功能、规格、优惠、销量、认证、库存或效果；不出现 SKU、成本、毛利、退货率、月销售额等内部字段。
- 高风险新闻的三个平台状态均为 `not_generated`，内容均为 `null`。
- 无商品匹配时 `product` 为 `null`，平台状态为 `not_generated`，页面展示暂无适合商品。
- 弱关联时 `shouldGenerate=false`，不生成策略或平台文案；卡片说明“不建议强行借势”，不可显示成生成失败。
- strong/medium 的 `relationshipPath` 不超过 3 个节点；weak 结果可保留更长路径解释牵强环节，但不得因此继续生成。
- 正常结果的微博、小红书和短视频都使用同一 `contentStrategy`，平台只改写表达形式。
- 敏感健康议题不能出现在普通商品的营销情绪钩子或策略中。
- 成功结果显示折叠的“为什么这样写？”策略解释；默认不展开。

## 新闻链接验收

- 合法 HTTP/HTTPS URL 显示“查看原文”和“搜索该新闻”。
- 空字符串、非法 URL 或非 HTTP(S) URL 不显示“查看原文”，仍显示“搜索该新闻”。
- 搜索入口使用新闻标题；即使原文页面 404、跳转、需要登录或无法访问，卡片仍保留标题、摘要和搜索入口。
- 链接页面不可访问不影响新闻分析、商品匹配和文案生成流程。

## 建议执行顺序

1. Mock 模式检查以上九个关键词及高风险、无商品状态。
2. 使用真实 LLM 对前五个可营销关键词检查三平台差异、小红书质量和事实约束。
3. 对新闻卡片分别检查有效、空、非法 URL；手动确认失效原文仍可从搜索入口继续查找。
4. 记录未通过项及对应关键词，修复后重跑相关场景。
5. 执行 lint、TypeScript 检查和 production build。
